# Python Modules – Practice

This repository contains my practical exercises and training related to **Python Modules**.

The goal of this repository is to understand how Python modules work and how to organize and reuse code across multiple files.

## Topics Covered

* Creating Python modules
* Defining functions inside modules
* Importing modules
* Importing specific functions from a module
* Using functions from another file
* Understanding module attributes
* Dynamic imports
* Accessing module attributes using `getattr`
* Practicing modular and reusable code

## Practice

The exercises in this repository are based on my training with **CodeGym** and additional practice exercises.

Each exercise is designed to strengthen my understanding of Python modules through practical implementation.

## Technologies

* Python 3
* Visual Studio Code
* Git & GitHub

## Learning Goal

Build a strong understanding of Python's module system and develop the ability to structure programs into reusable and maintainable components.
